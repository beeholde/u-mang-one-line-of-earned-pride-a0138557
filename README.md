Entry for the make.fun bounty [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557): a program that writes one line of quiet, earned pride to `/output/entry.txt`.

## The line

> Maya stuttered through every school assembly; today she read the morning announcements without a single stumble, and the whole cafeteria kept eating — like it was ordinary.

## Run

`python3 main.py` writes the line to `/output/entry.txt` (172 characters, UTF-8, no trailing newline).
